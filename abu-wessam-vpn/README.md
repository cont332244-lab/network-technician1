# أبو وسام VPN

نسخة أندرويد أولية تعرض سيرفرات VPN Gate العامة وتسمح بتصدير ملفات إعداد OpenVPN.

## الحالة والشفافية
- تعرض التطبيق بيانات السيرفرات التي يعيدها مصدر VPN Gate العام.
- زر التصدير يجهز ملف إعداد OpenVPN؛ يلزم استيراده في عميل OpenVPN متوافق للاتصال.
- هذه النسخة **لا تنشئ نفق VPN داخل التطبيق نفسه**. لا تستخدمها كأنها عميل VPN مكتمل حتى يتم دمج محرك OpenVPN واختباره.
- السيرفرات تطوعية، وقد تتوقف أو تكون بطيئة. لا تستخدمها للأنشطة الحساسة أو لتبادل بيانات سرية.

## البناء
يتطلب JDK 17 وAndroid SDK Platform 35 وGradle 8.9 أو أحدث متوافق مع Android Gradle Plugin 8.7.3.

من هذا المجلد:
```sh
gradle assembleDebug
```
ملف APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## المصدر
واجهة قائمة السيرفرات: https://www.vpngate.net/api/iphone/
